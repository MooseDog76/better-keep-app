# Security

**Found a security problem?** Please tell me privately: email feedback@ablememo.com. I'll reply within 14 days.

- Only the newest version gets fixes. AbleMemo updates itself.
- Your notes are kept in your own private account. The database's row-level security rules mean only you can read them
  (checked by `tests/rls-test.sql`).
- If I learn a security hole is being used, I'll fix it, release, and tell users the same week (a safety notice).
- I'll give at least 12 months' notice before AbleMemo stops. Download a backup any time from Settings.
- The app is built following a written set of checks (the Safety Net).
